04 / FAQ · 常见疑问与隐私说明

使用前你可能想知道的事

注册账号需要绑定邮箱或手机号吗？

不需要。只需设置一个「用户名 + 密码」即可 5 秒完成注册，用来保存你的会员状态和跨设备同步课程记录。因为未绑定邮箱，请妥善记住密码。

支持微信和支付宝付款吗？怎么开通会员？

支持。在工作台右上角点「登录 / 升级」，可直接使用微信或支付宝扫码支付 ¥4.9（Pro）或 ¥8.9（Ultra）并备注你的用户名，输入激活码后立即解锁全部功能。

只填 API Key 不选模型能直接用吗？

可以。设置面板会自动识别 Gemini、DeepSeek、OpenAI 等常见服务商，模型栏留空即自动匹配该厂商的默认高性价比模型，也可以自由手打任意最新模型名称。

支持哪些格式的课件？教授发的是 PPTX 怎么办？

目前专注支持 PDF 格式，以保证公式、图表和排版 100% 原封不动呈现且在浏览器本地零等待渲染。如果是 PPTX，在 PowerPoint 或 WPS 里「另存为 PDF」只需两秒即可上传。

我的课件 PDF 和 API Key 会上传到服务器吗？

PDF 课件只在你的浏览器内存中渲染，绝不上传原文件；个人 API Key 仅保存在你当前浏览器的本地存储中。课程笔记按账号独立隔离，他人无法查看。

哪些浏览器使用体验最好？

语音实时转写和独立画中画双语置顶窗依赖桌面端 Chrome 或 Microsoft Edge 116 及以上版本，建议在笔记本电脑上配合教室麦克风或网课声音内录使用。
